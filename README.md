 Employee Search Application

## 📌 Project Overview

Employee Search is a web application developed to manage and search employee information. The application allows users to view employee details, search employees, and perform basic employee management operations through a user-friendly interface.

## 🚀 Features

- Employee Registration
- Employee Search
- View Employee Details
- Update Employee Information
- Delete Employee Records
- Search and Filter Employees
- REST API Integration
- Database Management
- Responsive User Interface

## 🏗️ Project Architecture

The application follows a layered architecture:

- **Controller Layer** – Handles HTTP requests and responses.
- **Service Layer** – Contains business logic.
- **Repository Layer** – Handles database operations.
- **Entity/Model Layer** – Defines application data models.
- **Database Layer** – SQL Server database with Entity Framework Core.

## 🔄 Application Flow

Angular UI  
↓  
ASP.NET Core Web API

## ▶️ How to Run the Project

### Backend

1. Clone the repository.
2. Open the backend project in Visual Studio.
3. Configure the SQL Server connection string in `appsettings.json`.
4. Run Entity Framework migrations if required.
5. Build and run the ASP.NET Core Web API.
6. Open Swagger to test the APIs.
